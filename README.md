# Simulated End-to-End System

This is a mock fullstack project that simulates client-side, server-side, and database interactions using JavaScript, HTML, and CSS.

## Features
- SPA interface using HTML, CSS, and JS
- Simulated REST API with FAJAX (Fake AJAX)
- Client-side and server-side logic separation
- JSON-based data structure
- LocalStorage for data persistence

## Technologies
- HTML + CSS + JavaScript
- FAJAX (Fake AJAX)
- REST API structure
- LocalStorage (simulated database)

## Project Structure
- `/client` - client-side code
- `/server` - simulated server logic
- `/db` - fake database interactions
